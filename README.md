# Practical Deep Learning - Atelier Data Science

This repository supplements the Practical Deep Learning course taught during the spring semester of 2024 at the Université Lumière Lyon 2. 
The course is part of the "Atelier Data Science".

Lecture and practice materials for each week are stored in the `./n*` folders. You can run all Jupyter Notebooks locally or in Google Colab.

#### Useful links

**DL foundations**
- A lecture on backpropagation (Karpathy): https://www.youtube.com/watch?v=59Hbtz7XgjM 
- Interactive neural network playground: http://playground.tensorflow.org/
- Demo of momentum (gradient descent): http://distill.pub/2017/momentum/
- PyTorch Tutorial: https://www.youtube.com/watch?v=VMcRWYEKmhw

**CNNs**
- Convolutional NNs: https://cs231n.github.io/convolutional-networks/
- CNN Trainer in browser: https://cs.stanford.edu/people/karpathy/convnetjs/demo/cifar10.html
- Interpreting neural network predictions (highly recommended): https://distill.pub/2018/building-blocks/

**Training Tricks in DL**
- Lecture on nonlinearities, initializations and other tricks in deep learning: https://www.youtube.com/watch?v=GUtlrDbHhJM
- Lecture on activations, recap of adaptive SGD and dropout: https://www.youtube.com/watch?v=KaR4lIdI1MQ
- DL cheatsheet: https://stanford.edu/~shervine/teaching/cs-229/cheatsheet-deep-learning
- Notes on initialization in DL: https://www.deeplearning.ai/ai-notes/initialization/index.html 
- Explanation of memory allocation in PyTorch: https://pytorch.org/docs/stable/torch_cuda_memory.html
- https://docs.nvidia.com/cuda/cuda-c-programming-guide/index.html#the-benefits-of-using-gpus
